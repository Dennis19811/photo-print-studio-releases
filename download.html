🪟 Windows המחשב שלך

Windows 10 / 11, 64-bit

הוראות התקנה ב-Windows
  1. הורד את קובץ ההתקנה PhotoPrintStudio-Setup-…exe (כ-600 MB — ההורדה יכולה לקחת כמה דקות).
  2. פתח את הקובץ שהורד (לחיצה כפולה).
  3. אם מופיע מסך כחול של Windows protected your PC / SmartScreen: לחץ על More info (מידע נוסף) ואז על Run anyway (הפעל בכל זאת). זה קורה כי ההתקנה עדיין לא חתומה דיגיטלית — זה תקין.
  4. אשר את בקשת ההרשאות של Windows (Yes / כן) והמתן לסיום ההתקנה. התוכנה תיפתח אוטומטית בסיום.
  5. חבר את המדפסת ב-USB. עדכונים עתידיים יורדים אוטומטית מתוך התוכנה.

🍎 Mac המחשב שלך

איזה Mac יש לך? לחץ על (תפוח, פינה שמאלית עליונה) ← אודות ה-Mac הזה. אם כתוב שבב / Chip Apple M1–M4 → בחר "שבב Apple". אם כתוב מעבד / Processor Intel → בחר "Intel".

הוראות התקנה ב-Mac
  1. הורד את קובץ ה-.dmg המתאים למחשב שלך (כ-600 MB).
  2. פתח את הקובץ שהורד — ייפתח חלון עם האייקון של Photo Print Studio ותיקיית Applications.
  3. גרור את Photo Print Studio לתוך Applications (יישומים).
  4. פתח את Applications ← לחיצה כפולה על Photo Print Studio.
  5. חבר את המדפסת ב-USB.

⚠️ בפתיחה הראשונה macOS יגיד שלא ניתן לאמת את האפליקציה

זה קורה כי הגרסה הנוכחית עדיין לא חתומה ע"י Apple. אל תלחץ על "העבר לפח / Move to Trash". במקום זה:

  1. לחץ סיום / Done בהודעה.
  2. פתח הגדרות המערכת (System Settings) ← פרטיות ואבטחה (Privacy & Security).
  3. גלול למטה עד לקטע אבטחה — תופיע שורה על Photo Print Studio שנחסמה. לחץ פתח בכל זאת (Open Anyway).
  4. הזן את סיסמת המחשב (או Touch ID) ← לחץ פתח (Open). מעכשיו האפליקציה תיפתח רגיל.

אם הכפתור "פתח בכל זאת" לא מופיע — פתח את Terminal (מסוף), הדבק את הפקודה הבאה ולחץ Enter:

xattr -dr com.apple.quarantine "/Applications/Photo Print Studio.app"

📱 iPad המכשיר שלך

עמדת סלפי — הדפסה ישירה מהאייפד למדפסת בכבל USB. ההתקנה זמינה רק לאייפדים שנרשמו מראש.

🤳 לעמוד ההתקנה באייפד
הוראות התקנה באייפד
  1. פתח את הקישור מהאייפד עצמו (ב-Safari).
  2. לחץ על התקן באייפד ואשר. האייקון יופיע במסך הבית.
  3. עקוב אחרי ההוראות בעמוד ההתקנה (מצב מפתח, אישור המפתח, הפעלת הדרייבר).

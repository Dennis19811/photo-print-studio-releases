Photo Print Studio — הדפסה ישירה מהאייפד למדפסת DNP בכבל

⬇️ התקן באייפד
  1. לחץ על הכפתור ← התקן. האייקון יופיע במסך הבית ויטען דקה.
  2. הגדרות ← פרטיות ואבטחה ← מצב מפתח ← הפעל ← הפעלה מחדש ← אישור.
  3. פתח את האפליקציה פעם אחת (אם מופיע "מפתח לא מהימן": הגדרות ← כללי ← VPN וניהול מכשיר ← Denis Griniakov ← בטח).
  4. חבר את המדפסת ב-USB (דרך הרכזת). הגדרות ← כללי ← דרייברים ← הפעל PPSUsbDriver ← הפעלה מחדש.
  5. פתח את האפליקציה ← ⚙️ ← 🔌 בדיקת מדפסת.
הקישור עובד רק על אייפדים שנרשמו (UDID). התקנה מחדש על גרסה קיימת שומרת את ההגדרות.
